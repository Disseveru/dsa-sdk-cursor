# Start Here — Phone Only, No Coding

This guide is for you if you only have a phone (like a Moto G) and do not want to touch any code or use a computer.

## What you need

1. **Your Moto G** (or any Android phone)
2. **MetaMask app** — free from the [Google Play Store](https://play.google.com/store/apps/details?id=io.metamask)
3. **A little ETH** in MetaMask — for small transaction fees (not the full trade amount)
4. **The app link** — open this in Chrome on your phone:

   **https://disseveru.github.io/dsa-sdk-cursor/**

   *(If that link is not live yet, ask whoever set this up for the current URL.)*

## Step-by-step (about 5 minutes)

### 1. Install MetaMask
- Open Play Store → search "MetaMask" → Install
- Open MetaMask → Create a new wallet (or import if you already have one)
- **Write down your secret recovery phrase** on paper and keep it safe
- Buy or transfer a small amount of ETH into the wallet (for fees)

### 2. Open the app on your phone
- Open **Chrome** on your Moto G
- Go to the app link above
- Optional: tap the menu (⋮) → **Add to Home screen** so it works like a normal app

### 3. Connect your wallet
- Tap **Connect Wallet**
- Choose **MetaMask** when asked
- MetaMask will open — tap **Connect**, then **Approve**

### 4. Set up your earning account
- Tap **Set Up My Account**
- MetaMask will ask you to confirm — tap **Confirm**
- Wait a few seconds. You will see "Account ready"

### 5. Turn on Auto-Earn
- Flip the **Auto-Earn** switch to ON
- The app watches the market for you automatically
- When it finds an opportunity, tap **Earn Now**
- Confirm in MetaMask when it pops up

## That is it

You do not need to:
- Install anything on a computer
- Run terminal commands
- Write or read code
- Keep the app open 24/7 (but keep Auto-Earn on while you want it working)

## If something goes wrong

| Problem | What to try |
|---------|-------------|
| MetaMask does not open | Make sure MetaMask is installed and you are using Chrome |
| "Not enough funds" | Add a bit more ETH to MetaMask for gas fees |
| Connect fails | Close Chrome, reopen the app link, try again |
| No opportunities shown | Normal — profitable trades are not always available |
| Transaction failed | Gas fees still apply; try again later |

## Stay safe

- **Never** share your recovery phrase with anyone (including "support")
- **Never** send crypto to strangers who promise returns
- Only use money you can afford to lose
- Earnings are not guaranteed
